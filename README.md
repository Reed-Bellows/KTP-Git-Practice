# KTP-Git-Practice

## Run the game

From this folder, start the game in a terminal with:

```bash
python3 game.py
```

## How to play

- Red moves first. Enter a move as the starting square and destination, such as `b6 a5`, or type just a square (e.g. `b6`) to pick a piece and then choose where it goes.
- The board uses columns `a` through `h` and rows `1` through `8`.
- Pieces move diagonally. Captures are mandatory, and you must continue capturing with the same piece when prompted.
- Men move forward; kings (shown with a `K` next to the piece) can move in either direction.
- Type `moves` to list your legal moves, or `quit` to end the game.
