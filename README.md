# KTP-Git-Practice

## Run the game

From this folder, start the game in a terminal with:

```bash
python3 game.py
```

## How to play

- Red moves first. Enter a move as the starting square and destination, such as `b6 a5`.
- The board uses columns `a` through `h` and rows `1` through `8`.
- Pieces move diagonally. Captures are mandatory, and you must continue capturing with the same piece when prompted.
- Men move forward; kings (shown as uppercase `R` and `B`) can move in either direction.
- Type `quit` to end the game.
